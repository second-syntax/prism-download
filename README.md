# Prism 내려받기

**Prism** — 열지 않고 보고, 이름만 쳐도 찾는 Windows 탐색기. SECOND SYNTAX by WY.

한글(HWP·HWPX)·PDF·Office 문서를 프로그램을 열지 않고 탐색기에서 바로 보고, 드라이브 전체 파일을 이름으로 바로 찾아요.
이 저장소에는 **설치 파일만** 있어요. 소스 코드는 공개하지 않아요.

## 받기

| 팩 | 담는 것 | 받기 |
| --- | --- | --- |
| **Lite 팩** | 딱 필요한 것만: 탐색기 창 하나, 폴더 트리, 미리보기, 폴더·드라이브 전체 이름 찾기, 기본 파일 작업, 메모장·계산기·그림판 | [Prism-Lite-Setup-0.1.2.exe](https://github.com/second-syntax/prism-download/releases/download/simple-v0.1.2/Prism-Lite-Setup-0.1.2.exe) |
| Standard 팩 | Lite 팩 + 창 4개·탭, 도구 칸 나누기와 도구 별도 창, 정리·크기와 중복 확인·폴더 비교 | 공개 예정 |
| AI 팩 | Standard 팩 + AI가 함께 찾고 정리 | 준비 중 |

모든 버전은 [Releases](https://github.com/second-syntax/prism-download/releases)에 있어요.

**팩 이름이 바뀌었어요(2026-11-12).** 심플팩 → **Lite 팩**, 확장팩 → **Standard 팩**, AI팩 → **AI 팩**.
0.1.0·0.1.1은 이름을 바꾸기 전에 낸 판이라 "Prism 심플팩"으로 나와요. 그 위에 0.1.2를 설치하면 같은 자리에서 "Prism Lite 팩"으로 바뀌어요.

## 필요한 것

- Windows 11 64비트(x64)
- 설치 공간 약 350MB

## 설치

1. 설치 파일을 받아 실행해요.
2. **"Windows의 PC 보호" 창이 뜰 수 있어요.** Prism은 아직 코드 서명 인증서가 없는 새 프로그램이라서 그래요. **추가 정보 → 실행**을 누르면 설치돼요.
   - **스마트 앱 컨트롤**이 켜진 PC에서는 서명 없는 프로그램이 실행되지 않고, 넘기는 버튼도 없어요. 이런 PC에서는 아직 Prism을 쓸 수 없어요.
   - 회사 PC는 보안 정책 때문에 설치가 막힐 수 있어요.
3. 관리자 승인 없이 **내 계정에만** 설치돼요. 시작 메뉴에 "Prism Lite 팩"이 생겨요.
4. 글자 인식에 쓰는 Microsoft Visual C++ 런타임이 없는 PC라면, 설치 화면이 Microsoft에서 받아 설치하도록 안내해요(관리자 승인 한 번). 건너뛰어도 Prism은 설치되고, 글자 인식만 런타임을 설치한 뒤에 동작해요.

## 받은 파일이 원본과 같은지 확인

각 릴리스의 `SHA256SUMS.txt`에 설치 파일의 SHA-256 값이 있어요. PowerShell에서 확인해요.

```powershell
Get-FileHash .\Prism-Lite-Setup-0.1.2.exe -Algorithm SHA256
```

## 업데이트와 지우기

- **업데이트 알림**: 하루 한 번 이 저장소에 새 판이 올라왔는지 보고 알려 줘요. 스스로 받거나 설치하지는 않아요.
  - **도구와 더 보기**(탐색기 줄 오른쪽 끝) → **업데이트 알림 받기**로 끄고 켜요. **새 버전 확인**은 바로 확인해요.
- **눌러서 업데이트**: 0.1.2부터는 알림의 **업데이트**를 누르면 Prism이 설치 파일을 받아 확인한 뒤, **다시 시작해서 적용**으로 설치하고 다시 켜요.
  - 0.1.2 다음 판(0.1.3)부터 이렇게 올라가요. 0.1.0·0.1.1에서는 지금처럼 새 설치 파일을 받아 실행해 주세요. 같은 자리에 업데이트되고 설정과 기록은 남아요.
  - 업데이트 뒤 처음 켤 때 **바뀐 것**을 한 번 보여 줘요. 새 판이 두 번 이어서 켜지지 않으면 이전 판을 받을지 물어요.
- **지우기**: Windows 설정 → 앱 → 설치된 앱에서 "Prism Lite 팩"(0.1.0·0.1.1은 "Prism 심플팩")을 지워요.
  - 설정·찾기 기록·메모는 다시 설치할 때를 위해 남겨 둬요.
  - 완전히 지우려면 Prism을 지운 뒤 `%LOCALAPPDATA%\SecondSyntax\Prism` 폴더를 지워요.

## 개인정보

자세한 내용은 [Prism 개인정보처리방침](https://second-syntax.com/products/prism/privacy/)에 있어요.

- Prism은 계정이나 로그인이 없고, **파일 내용·이름·경로를 밖으로 보내지 않아요.** 사용 통계도 모으지 않아요.
- **의견 보내기**: 도구와 더 보기 → **의견 보내기**에서 쓴 글은 **'보내기'를 눌러야만** SECOND SYNTAX의 받는 주소(Cloudflare, `prism-api.second-syntax.workers.dev`)로 가요.
  - 함께 가는 것: 의견 종류, 쓴 글, 넣었을 때만 답 메일 주소, 쓴 자리(도구 메뉴 등), 프로그램 정보(팩·모드·버전·Windows 빌드·화면 배율·표시 언어 — 끌 수 있고 '내용 보기'로 그대로 보여요).
  - 오류로 꺼진 뒤에는 다음에 켤 때 기록을 보낼지 한 번 물어요. 기록(버전, 꺼진 때, 오류 종류, 함수 이름 줄)은 '보내기'를 누를 때만 가요.
  - 받은 의견은 1년 뒤 지워요. 보낸 곳의 IP 주소는 저장하지 않아요.
- Prism이 인터넷을 쓰는 때
  - 새 버전 확인: 하루 한 번 GitHub(`api.github.com`)에서 이 저장소의 릴리스 목록을 읽어요. 요청 자체(IP 주소와 고정된 이름 "SECOND-SYNTAX-Prism")만 가요.
  - 알림에서 '업데이트'를 누를 때: GitHub에서 설치 파일과 SECOND SYNTAX가 서명한 목록을 받아요.
  - '의견 보내기'에서 '보내기'를 누를 때(위)
  - 계산기의 환율 탭을 열 때(유럽중앙은행 공개 환율)
  - OneDrive 같은 클라우드 파일을 열 때(그 서비스가 파일을 내려받음)
- HTML·한글(HWP) 미리보기는 Windows의 **Microsoft Edge WebView2** 엔진으로 그려요.
  - 엔진은 켜질 때마다 Microsoft Edge 설정 서버(`config.edge.skype.com`)에서 설정을 받아요. 엔진·Windows 버전과 기기 식별 번호가 가고, 파일 이름·내용·경로는 가지 않아요. 앱에서 끌 수 있는 공식 설정이 없어요. 이 엔진의 SmartScreen 확인과 충돌 기록 전송은 꺼 두었어요.
  - 2026-11-26 0.1.2 설치본 측정(합성 파일): 아무것도 누르지 않은 동안 바깥 연결은 새 버전 확인 1건(GitHub)과 엔진의 설정 서버 2건이었어요. 의견 받는 주소로는 0건이었어요.
- Lite 팩과 Standard 팩에는 AI 기능이 없어요.
- 설치 파일을 받을 때의 접속 기록은 GitHub의 개인정보처리방침을 따라요. SECOND SYNTAX는 내려받기 횟수만 봐요.

## 사용 조건

- Prism은 무료로 쓸 수 있어요.
- 설치 파일과 프로그램을 다시 배포하거나, 고치거나, 디컴파일·역어셈블 같은 방법으로 분석(리버스 엔지니어링)하지 말아 주세요. 법이 허용하는 범위는 예외예요.
- Prism은 "있는 그대로" 제공해요. 쓰다 생긴 문제에 대해 법이 허용하는 범위에서 책임을 지지 않아요. 중요한 파일은 따로 백업해 두세요.
- Prism에 들어 있는 오픈 소스 구성 요소는 각자의 라이선스를 따르고, 그 고지는 설치 폴더에 함께 있어요.
